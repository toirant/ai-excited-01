# Golden Koi Rising — ai-excited-01

A colossal golden koi leaps up a waterfall that flows upward into a starry
night sky — the water climbs toward the stars and the koi climbs with it.
Built for make.fun's AI-judge image contest: one image made to excite the
judge, with a program (`main.ts`) that copies it to `/output/entry.png`.
